# 架构决策记录（ADR）

这里记录 Loong OS 中影响深远、难以回退的架构决策：背景是什么，选了什么，放弃了什么，代价是什么。整体规划见[技术规划](../技术规划.md)。

## 索引

| 编号 | 决策 | 状态 |
|---|---|---|
| [0001](0001-基础发行版-alpine.md) | 基础发行版选用 Alpine Linux 3.24，设备层复用 postmarketOS v26.06 的内核与固件 | 已接受 |
| [0002](0002-shell-rust-smithay.md) | Shell 采用 Rust + Smithay 自研 Wayland 合成器 `loong-shell` | 已接受 |

| [0004](0004-启动与-ota-ab.md) | 只读 erofs + A/B 双分区，自写 initramfs，提供 `uefi-sdboot` / `android-abl` 两种启动后端 | 已接受 |

## 编写约定

- **文件名**：`NNNN-简短标题.md`，编号递增，不复用已有编号。
- **固定结构**：
  1. **状态**：提议 / 已接受 / 已废弃 / 被 ADR NNNN 取代
  2. **背景**：要解决什么问题，有哪些约束和已验证的事实
  3. **决策**：选了什么，关键参数是什么
  4. **备选方案及不选原因**
  5. **影响 / 后果**：带来的好处、代价、风险和后续工作
- 已接受的 ADR 不改写结论。如果决策发生变化，新建一篇 ADR，并把旧 ADR 的状态改为“被 ADR NNNN 取代”。
